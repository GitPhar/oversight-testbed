# (working title — see CONTEXT.md §0)

[![Reproduce](https://github.com/GitPhar/oversight-testbed/actions/workflows/reproduce.yml/badge.svg?branch=main)](https://github.com/GitPhar/oversight-testbed/actions/workflows/reproduce.yml)

**What this is.** An AI (Claude) runs small research programs. Before each test it writes down its odds that the test will pass a rule fixed in advance. A person (Sean Pharris) writes down his own odds separately, without seeing the AI's. A second Claude session that has not seen the work tries to break every result, and its report is published either way. The AI's odds are scored in public against what happened; the person's will be once enough bets carry them. The point is not the volume of results but whether anyone, AI or human, can be trusted to choose and judge research.

**What it has found, and whether it is new.** Each line below is one finding, the Claude models it was shown on (Haiku, Sonnet and Opus mean Claude Haiku 5.5, Sonnet 5.5 and Opus 5.5), and the verdict of [paper/novelty.md](paper/novelty.md), which checked each finding against the published literature on 5 November 2026. *Known* means a paper already reports the same result; *partly new* means the kind of result is in print but one comparison made here is not; *new* means no prior statement was found. Nothing here is both new and replicated.

## The five commitments

1. **Odds before data.** Every bet carries the AI's odds and the person's odds, recorded separately, before any data are seen. (<!--n:human_n-->12<!--/n--> scored bets carry the person's odds so far; `ledger/brier.md`.)
2. **Cheapest test first.** Archived data before new API calls, API calls before hardware; budgets enforced in code; stop rules; a run stops at its first refusal.
3. **No result without a check.** An independent session that has not seen the work tries to break every result, and its report is published whether or not the result stands.
4. **Nothing disappears.** Every dead direction stays on the map with the reason it died.
5. **Full reads first, all fields.** Every program starts from adjacent research read in full, its "what to do next" extracted and filtered by cost and whether it can fail.

## Programs

Every program lives in this repository under `programs/`, with its git history imported. There are no separate program repositories.

- Program 1, [The Entangled Mind](programs/entangled-mind/): can a quantum-style encoding of a model's competing beliefs flag its wrong answers? Closed, negative, with a diagnosis. It left a live question: does a model's stated confidence report a fixed belief? (On Haiku, mostly not; on Opus, partly yes.) Its original repository, [GitPhar/entangled-mind](https://github.com/GitPhar/entangled-mind), is kept untouched as the historical record.
- Program 2, [Other Minds](programs/other-minds/): does a model reason about another mind the way it reasons about its own? Eight verdicts on Haiku and none passed; the one Haiku effect did not repeat on Sonnet or Opus. A ninth bet (om-p2-7, the first carrying Sean's odds) has a results file saying fail, audited and standing, not yet scored in the ledger.
- Program 3, [Nature-Graded](programs/nature-graded/): the same AI's odds, graded by a real quantum chip instead of by a language model. The chip is a referee, never a computing resource (`operators/hardware.md`). Four fails, two untestable, one unscored pass; the 3 November question closed on 5 November.
- Program 4, [Settled Science](programs/settled-science/): can the AI tell which way published findings came out? Five scored passes, none yet repeated, all on one model and items written by the same model family; a sixth was reversed to undetermined by audit.
- Program 5, [Self-Grading](programs/self-grading/): does a model grade its own work more kindly than someone else's? Opened 5 November. Two tests came back "no" on all three models; one came back "yes" for a planted exaggeration on Haiku and Opus (a known effect).
- Program 6, [Test Awareness](programs/test-awareness/): does a model behave differently when it thinks it is being tested? Opened 5 November. Two nulls (no sandbagging on Sonnet or Opus; and "told it is an evaluation" vs "told it is real" with no reading on two models), one untestable, two withdrawn before data.
- Program 7, [Said vs Did](programs/said-vs-did/): does the confidence a model states predict what it then does? Opened 5 November. First wave: no hit in three tests.

## Ledger, audits, map, site

`ledger/bets.jsonl` (every bet, its odds and its outcome), `ledger/human-odds.jsonl` (Sean's 26 lines), `ledger/steers.jsonl` (every human decision), `ledger/audits/` (every independent check), `map/` (every path considered), `site/` (the public pages at https://gitphar.github.io/oversight-testbed/). The operators that populate them are described in `CONTEXT.md` §7.

**Reproduce everything with one command:** `python3 reproduce.py` (Python 3 and numpy, `pip install -r requirements-reproduce.txt`; no keys, no network). It rebuilds every ledger table, the site data and every program's results tables from the archived files and checks them against what is committed; each program also has its own `programs/<name>/reproduce.py`. The badge above is that command's state on `main`, run on every push and daily (`.github/workflows/reproduce.yml`).
