# Design reviews

One file per pre-registration, `<bet-id>.md`, written by a fresh auditor session that dry-runs the design (checks D1–D10, no paid calls) before the bet's first call. The verdict is go, fix-first or redesign. The procedure and file format are in `operators/design-review.md`. Mandatory from 2026-11-04 17:00 America/Denver; `ledger/check_prereg.py` checks for it.
