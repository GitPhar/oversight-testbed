# Design review of om-p2-14

## In plain English

As built, the Haiku test can answer its question. The equivalence rule is sound. The statistic is om-p2-4's own-uptake block to four decimals (−0.1934 on the archive), the BCa interval agrees with scipy's, and the ±0.05 margin has real power: equal labels pass 0.95–1.00 under three different null worlds, and a true gap of about −0.03 passes only 6.5% of the time. Five things need fixing before any call; none changes what is tested.
1. The cost estimate ignores prompt length. The prediction prompts are twice as long as om-p2-6r's, so Sonnet should cost about $1.94 against a $2.00 cap. A 5% overrun stops Sonnet and means Opus is never called.
2. A predictor that ignores the label and knows nothing (always 50 in both arms) passes with an interval of [0, 0].
3. The pass sentence says "reads itself no better than a stranger" even when the interval sits inside the margin but excludes 0. That happens in 10–14% of runs in the null worlds. The pass sentence also says "16 vignettes" for Opus, which runs on 8.
4. §7 says a stopped model reads not_run, but the code resumes after an error and scores the resumed run.
5. For Sonnet and Opus, the "distance classes" are Haiku's planted distances, not the distance from their own base. Also, the archive does hold Sonnet's and Opus's base on these exact prompts (om-p2-6r).

**D1. A stranger can apply the rule: flaw (two gaps).** On synthetic tables `reading()` returns exactly one verdict for every case: pass [−0.049, 0.049]; undetermined [−0.05, 0.049] and [−0.02, 0.06]; self_better [−0.06, −0.01]; sam_better [1e-4, 0.3]; untestable at 11 complete vignettes; not_run on a missing call. There are two gaps.
- (a) §5 lists pass, then self_better ("upper bound below 0"), then sam_better, but it never says which comes first. An interval of [−0.04, −0.01] meets both pass and self_better. The code returns pass (`reading([-0.04,-0.01])` → pass), but a stranger reading §5 could return either.
- (b) §7 says "Stop on any refusal or error; a stopped model and every later one read not_run". The code makes a non-refusal error resumable: no refusal is on record, so `GuardedCaller` loads the cache and carries on. `analyse()` then scores the resumed run because it checks only completeness. Run with a stub: an error at Haiku's 1,000th call gives label `untestable`; the resumed run gives `fail`. The resumed result still carries the old `stop_record` with reason `error`. Whether a resumed Haiku run is the scored run is therefore not written down. The SDK client retries 4 times (`llm.client()`), so an error is unlikely, but with 3,840 calls it is foreseeable. → F1, F4.

**D2. Every manipulation takes effect: flaw (Sonnet/Opus distance), holds for Haiku and the label.**
- *The label.* The two prompts differ only in the subject (word diff: "you, … assistant." / "assistant called Sam."; "yours"/"Sam's"; "your"/"Sam's"; "you"/"Sam"). The output follows the label: in the world where self equals the truth and Sam over-predicts by 0.2·D, Haiku reads self_better −0.194. In the world where Sam is shifted by k = 0.025, 0.05, 0.075 or 0.10 in uptake units, the pass rate falls 0.905 → 0.065 → 0 → 0. The parameters printed match §2: Haiku thinking disabled/100, Sonnet `between_tools`/200, Opus effort low/4000; repeats 10 / 3+3 / 1+2. The Opus vignettes are co-lin06, co-lin08, co-lin10, co02, co05, co07, co08, co10 (seed32 3695849154).
- *The distance, on Sonnet and Opus.* The design pools cells into |d| ∈ {10, 30, 60} classes, but d is Haiku's planted distance (A comes from program 1). On Sonnet and Opus, D = A − their own base. om-p2-6r's archive measured that base this morning, with the **identical** `ask()` prompt on the same 32 statements: `sb.py` confirms the prompt text and item set are identical, 3 Sonnet and 2 Opus repeats. Against that base:
  - Sonnet's base differs from Haiku's by SD 0.13 (Opus 0.17).
  - Sonnet's "10" class keeps 49 cells with |D| from 0.05 to 0.68; 43% have |D| < 0.10, where u divides a few rating points by a few rating points.
  - 15 of Sonnet's class-10 cells are dropped.
  - 3 kept Sonnet cells (5 on Opus) were planted on the far side of the model's own base.

  So for these two models, "u_own_10/30/60" does not mean pull at 10/30/60 points. The models are unscored, but the tables and sentences will name them that way. → F5.

**D3. Every control can fail: holds.** There is no control band. The untestable gate rejects a table with 11 complete vignettes ("11 vignettes with cells in every distance class (12 needed)") and accepts one with 12. not_run is returned for a model with any missing or refused call (stub: refusal at a Sonnet call → Sonnet and Opus not_run, `refusal-p2-14.md` written, and a new `GuardedCaller` exits "a refusal is on record"). The gate refuses with no review, with an unconfirmed fix-first, and when any second `om-p2-14*.md` says redesign. It passes on go or on a confirmed fix-first.

**D4. Rivals are matched: holds.** The statistic is antisymmetric: swapping arms gives +0.1934 against −0.1934. In the null world where both arms are drawn from the self arm's archive, self_better and sam_better occur 0 times in 200 runs, so neither label wins by construction. Both arms read the same transcript, are interleaved within each repeat by one beacon permutation, and are scored against the same truth.

**D5. A dumb baseline is beaten, and the design can see the effect: flaw (the dumb baseline). The margin and power hold.**
- *Margin and power* (`pow.py`, the code's own `tables`/`bca_interval`/`reading`, 200 runs × 1,000 resamples, seeds as in the dry run):
  - P(pass) under the null worlds: labels exchangeable 0.98; both arms drawn from the self arm's archive (errors near 0, where |·| is least smooth) 0.95; both from Sam's 1.00.
  - Equivalence power by true gap: self arm plus a Sam shift of k = 0.025 (point ΔMAE −0.008) 0.905; k = 0.05 (ΔMAE −0.032) 0.065; k = 0.075 (−0.057) 0.00.

  So the margin is fixed, power at the null is ≥ 0.95, and the rule rarely passes a true gap of 0.03 or more. It is conservative, not lax. The boundary uses EPS correctly.
- *The dumbest predictor.* Any label-blind predictor passes. A stub answering 50 to every prediction in both arms gives ΔMAE ≡ 0, BCa [0.0, 0.0], reading **pass**, and the frozen sentence "the model's predictions … were as accurate when … labelled as its own as when … labelled as another AI's … it reads itself no better than it reads a stranger". om-p2-4 had a gate against this (both arms above chance); this design dropped it. On the archive both arms beat the no-uptake predictor (u = 0, block MAE 0.452) by a wide margin (self 0.013, Sam 0.208), so a gate would not bind on plausible data. It is still needed so that a pass carries the noun "predictions of its own-answer pull". → F2.

**D6. Foreseeable execution risks: flaw (cost), holds for refusal and parsing.**
- *Refusal and parsing.* The base and three-turn re-rating conversations ran 1,440 times on Sonnet and Opus in om-p2-6r under these settings and max_tokens, with no refusal and no max_tokens stop. The prediction wrapper ran 13,796 times on Haiku. The wrapper is new to Sonnet and Opus, but the content is everyday probability vignettes and Haiku, the scored model, runs first. No pilot is needed for refusal.
- *Cost* (`cost2.py`). `EST` charges every Sonnet call om-p2-6r's flat $0.000862. But om-p2-14's prediction prompts average 1,009 characters against om-p2-6r's 322 (base) and 573 (three-turn). om-p2-6r's own costs give a slope of 7.3e-7 $/character on Sonnet (base $0.000700, three-turn $0.000883), and Haiku's om-p2-4 archive gives the same 0.35 tokens/character. Prompt-length-aware estimates: Sonnet **$1.94** (§3 says $1.57; cap $2.00); Haiku $0.22 (cap $0.30); Opus $1.13 if its prediction calls think as much as om-p2-6r's three-turn calls (§3 $1.28; cap $1.70).
- *What a cap does.* With the stub charging those costs, every model completes. With Sonnet's costs 5% higher, Sonnet hits its cap at $2.007 with 29 calls missing, reads not_run, and **Opus is never called** (`main()` breaks). If Opus's prediction output runs at twice om-p2-6r's, Opus caps at $1.70 and reads not_run. P15 records Opus at 1.5–2.5× estimates. So the reported half of the design (rule 12, all three models) can be lost to a cap, at a cost of $2–3.7. → F3.

**D7. Comparisons match: holds.** The scored comparison (self against Sam, on Haiku) differs only in the subject named. Same model, settings, schema, date, transcript and truth; order is interleaved. Haiku's truth date (2026-11-03/04) is common to both arms. No cross-model claim is made, and §6 says that Sonnet and Opus run under their own settings.

**D8. The verdict sentences are written: flaw.** Every verdict has a frozen sentence, but four of them claim more than the design can carry.
- (i) The pass sentence ends "On this test it reads itself no better than it reads a stranger". In the null worlds, 9.5% (exchangeable), 14% (both like self) and 11.5% (both like Sam) of runs pass with an interval wholly on one side of 0, where the model does read itself detectably better or worse, by less than 0.05.
- (ii) The pass sentence hard-codes "on program 1's 16 vignettes" and is reused for Opus, which runs on 8.
- (iii) "how far its own planted earlier answer pulls its re-rating": the statistic is the average pull in each of three distance classes (om-p2-4's effect level), not cell by cell. om-p2-15 showed this morning that the two readings can disagree.
- (iv) §1's "A fail means it reads itself detectably differently (most likely better)" is wrong for undetermined, which is a fail. In the shifted worlds above, undetermined is 0.93–0.99 of outcomes.

→ F1.

**D9. One item cannot decide it: holds.** Leave-one-vignette-out is pre-registered and coded. In a synthetic world where a equals b except one vignette (co04) with a large Sam error, the reading is undetermined, dropping co04 flips it, and the sentence appends "Leaving out one vignette changes the reading: without any one of co04." The reading itself is unchanged, as §5 says. A minor point: the leave-one-out intervals use 4,000 resamples against the primary's 10,000, so a flip within Monte Carlo noise of a bound is possible. Report the LOO bounds beside the flips.

**D10. Machinery: holds.**
- Budget: per-model and total caps are checked under a lock before every call, with at most 8 calls in flight past a cap.
- Refusal: stop on refusal in code, the refused job cached, a refusal file written, and no resume (tested).
- Scale: one direction ("0 = certainly false, 100 = certainly true" in the prediction wrapper and in program 1's question).
- Cache: keyed by job and content-hashed (model, settings, max_tokens, messages, schema), asserted on every hit and again at analysis.
- Seed: `ledger/seed.py` recomputes items/order/boot as 3695849154 / 47199670 / 1837414171; pulse 10:54:00 follows the 10:53:06 commit.
- Lesson: ls-om-p2-14 matches §0 word for word (`check_prereg.py` L1–L3 ok, H1 ok; R1 waits for this file).
- Ledger: the bet row, D20 and br-012 agree with §0 and §3.
- Drop rule: `abs(D) < 0.05 - EPS` keeps the same 162 Haiku cells as om-p2-4's `abs(D) < 0.05`. The one boundary cell, co-lin06 X +10 at |D| = 0.05000000000000004, is kept by both. The tolerance is on the keep side, as program 1's "< 0.05 is dropped" intends.
- Block statistic: matches om-p2-4's own-uptake block exactly. On the archived 5 predictions, `block_stat` gives −0.1934, and om-p2-4's `effects()` gives −0.1934 with identical class means (measured .7077/.4430/.2055, self .7103/.4208/.2201, Sam .8429/.6675/.4653).
- BCa: on the archive the code gives [−0.292, −0.135], scipy's BCa (same statistic, vignette indices) [−0.283, −0.136], and the percentile interval [−0.238, −0.020]. The z0, jackknife acceleration and adjusted quantiles are textbook.
- Mid-run stops: a model that stops reads not_run and blocks later models, as §7 says (but see F4 on resume).

**D11. The bet can both pass and fail: holds.** The design names two worlds. In the hypothesis world (labels exchangeable) P(pass) is 0.98, and 0.95–1.00 across the three null worlds above. In the other world (as archived) P(fail) is 1.00. Both are above the floor. A caveat the odds already carry: the archived world is the expected one. The label shifts predicted own uptake by −0.21 [−0.28, −0.14] (om-p2-4 audit), and fresh draws of the same prompts should reproduce that. So a realistic P(pass) is probably below the engine's 0.10. The information is in turning an exploratory result into a confirmatory one, and in scoring Sean's 0.75.
