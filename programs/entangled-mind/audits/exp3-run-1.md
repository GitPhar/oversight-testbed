## Plain-English summary of the audit
The numbers in the result file are right: I rebuilt every pair from the raw conversations and got the same 27 of 218 pairs differing, the same ρ (−0.034, +0.082), the same bootstrap CI on the difference ([−0.285, +0.063] with my seeds against [−0.284, +0.060]), the same permutation p (0.25) and 34 of 40 items (85%) answering the same in all 5 baseline runs. The pre-registered verdict, "inconclusive", stands. What does not stand is the generalisation the project built on it. "The base model showed no detectable order effects" is a null from a design that can only detect large effects: a single pair needs a 0.8 shift to be significant, and the aggregate test is blind to shifts below about 0.2 when they sit only on the 33 pairs where the model ever varies. It is also contradicted by the project's own yes/no data: in experiment 4 run 1 the model's yes-rate on the first conjunct moved by +0.67, +0.50, −0.22 and +0.43 depending on order. And the test could never have discriminated the two models, because both predicted order effects of at most 4.6 points, below the 20-point resolution of 5 + 5 conversations. That could have been computed before any call was made. The README, v3, paper and biomimetic-map sentences that say yes/no answers do not move with order should be scoped to experiment 3's design.

## Holes found
1. **The generalisation "no order effects in yes/no form" is contradicted by the project's own data.** Experiment 4 run 1 (yes/no A/B questions, 100 calls per position) shows large, tightly bounded marginal order effects: OE_X = +0.67, +0.50, −0.22, +0.43 on four items (`results/exp4-run-1.json`, `phase2.*.stats.OE_X`). Experiment 3's null is specific to its design: considering two of the model's own contentions, then answering the main question, with 5 + 5 conversations. README.md:195, v3:60, paper.md:150 and biomimetic-map.md:36 turn that design-specific null into a property of yes/no answers. That is false on the archive.
2. **The test could not discriminate the models by construction, and this was knowable before any call.** Both predictions are computed offline. Δᴼ ≤ 0.046 (median 0.0025) and Δᶠ ≤ 0.017 (65% of pairs below 5 × 10⁻⁵, so heavily tied). The observed effect is quantised at 0.2 with R = 5. The Spearman ρ therefore ranks sub-point predictions against mostly-zero noise (191/218 observed values tied at 0). Both models predicted what was observed, "no detectable order effect", so the absence of order effects does not separate them. The Reading's "the reason is upstream of either model" overstates this. Neither model predicted an effect this design could see.
3. **The null is underpowered, and the wording says "no detectable" without saying what was detectable.** Only 33 of 218 pairs are ever non-constant. Effects confined to those pairs need about 0.2–0.3 to be found (58% and 97% power), and no single pair can be significant below a 0.8 shift.
4. **The quantum prediction used the as-run phase solver, whose frame drift was documented 71 s before the result commit** (D15, `ab929fe` 18:08:59; the result is `3241667` 18:10:06). `x_basis_state` calls `v2.fast_quantum_state`, and 20% of run-2 items have the yes camp more than 30° off the readout axis (D15). The exp3 file does not mention it. It cannot change the inconclusive verdict (hole 2 dominates), but the Δᴼ ranks are from a known-defective encoding.
5. **D13 changed both secondary tests and the budget 6 s after the first call.** Secondary 1's pre-registered comparison (baseline split halves) became an order-label permutation; secondary 2's Wilcoxon became a sign-flip test; and the $4 cap became $10 (the run cost $1.63). I ran the pre-registered version of secondary 1: the baseline 2-vs-3 split-half mean absolute difference is 0.060, larger than the observed 0.036. The conclusion is the same, so the change is harmless, but the timing claim "logged before any experiment-3 result" rests on a 6-second margin and on the runner not being in git when calls began.
6. **Item concentration.** h277 supplies 5 of the 27 non-zero pairs, and the leave-one-out ρ difference moves from −0.116 to −0.188 when it is dropped. Every leave-one-out estimate is negative, so the "leans classical" point estimate is not one item, but it is also not an inference.
