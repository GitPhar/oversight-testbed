## Plain-English summary of the audit
The run-2b numbers recompute exactly. G (the model's own confidence) has AUROC 0.82 [0.72, 0.90]. The shuffle null puts the real web below 198 of 200 random webs (p = 0.990). Arm F is all zeros. The timing does not hurt G's value, since G's prompt and scoring were in git before the first G call. It does mean "G beats the structural arms" is a comparison chosen after arms A–E had failed, so it should be reported as an un-pre-registered contrast. The contrast itself is real against A and E (G − A +0.28 [+0.10, +0.45], G − E +0.18 [+0.04, +0.32]). Against C (+0.14 [+0.02, +0.27]) and D (+0.17 [+0.02, +0.33]) it is only just significant and does not survive a Holm correction across the four comparisons. So "by a wide margin" and "far above every arm" are too strong. "Every arm built from the deliberation structure" is also wrong once the learned models are counted: on these same 80 items A2 scores 0.82 (a tie) and A2.1 scores 0.84. Finally, the file says arm F's window holds "1–6 configurations"; it holds 1–16.

## Holes found
1. **"Best by a wide margin" outruns the intervals.** G's lead over C (+0.14) and D (+0.17) has lower bounds of +0.015 and +0.017 and does not survive a Holm correction across the four G-vs-structure contrasts. Only G − A and G − E are comfortably clear.
2. **"Every arm built from the deliberation structure" is false once the learned models are counted.** On these same 80 items the learned A2 ties G (0.82) and A2.1 exceeds it (0.84). Both results were committed before or within minutes of this file (v2 18:50, v2.1 19:32). v3:845 and paper.md:23 turn this into "better than any analysis … we built", which is wrong.
3. **The G-vs-structure comparison is post hoc in motivation.** G's value was protected: its prompt and code were in git before the first call. But G was added after the primary test failed, and nothing in Addendum A pre-registers "G beats the structural arms" as a hypothesis. Several documents present it as the headline ("the best signal"). That headline is one of 6 pairwise comparisons, against arms chosen in advance, on one model and one 80-item set.
4. **Arm F's window size is misreported** (1–16, not 1–6).
5. **Single test set.** All of this rests on the same 80 items. The split analysis and the v2 and v2.1 secondary results reuse the same items, so they are not independent confirmation.
