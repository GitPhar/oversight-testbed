## Holes found
1. **λ_h = 0 in F2.1 is forced by scale, not learned.** λ_h ∈ [0, 2] multiplies U ∈ [0, 1], but F2.1's conflict scores are about 1e-5 to 1e-2. Any λ_h ≥ 0.02 makes the score effectively U alone (AUROC about 0.70 on train), so the hill-climb must sit at 0. For A2.1, small λ_h is flat on train and slightly better on validation, so 0 is one point in a flat region. "Fitted to zero in both families" therefore does not show that the hedge share carries no extra signal. It shows that the combination was mis-scaled for F2.1 and uninformative for A2.1.
2. **H was tested where it was found, then shrank.** W4 found hedge count AUROC 0.78 on the run-2 80 items. H's "held-out" 0.77/0.78 in v2 is the same computation on the same items. On the clean locked test H is 0.67 [0.57, 0.77], below A2 by 0.160 [+0.058, +0.258]: a textbook winner's-curse drop, and it is correctly reported as the locked-test number in v3:414.
3. **Power.** As in v2, the non-overlap criterion needed a gain of about 0.10 or more. The minimum detectable paired difference is about 0.115.
4. **The held-out edge is not separate evidence.** It is on the set that suggested v2.1 (disclosed). It is also on the same questions where Sonnet's A2 − F2 edge concentrates (see audits/sonnet-replication.md), so the "two" secondary edges are one item set.
5. **Misleading commit message** `d17b455` ("evaluation of the selected A2.1"): code only, written before any A2.1 existed.
