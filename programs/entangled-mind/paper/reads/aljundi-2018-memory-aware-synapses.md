# Memory Aware Synapses (MAS) — Aljundi, Babiloni, Elhoseiny, Rohrbach & Tuytelaars, 2018, ECCV (read as arXiv 1711.09601v4)
- url: https://arxiv.org/pdf/1711.09601
- field: machine learning
- read_depth: full (arXiv v4 incl. appendices)
- read_by: scout-bmq reader C, 2026-11-04
- what_tested: Weight importance = sensitivity of the network's OUTPUT (gradient of squared L2 norm of the output) to that weight, averaged over data points; needs no labels, so it can be computed on unlabelled test-time data and so protect what the model is actually used for. A local Hebbian variant (l-MAS) uses products of pre- and post-synaptic activations. Penalty as in EWC/SI. Compared to fine-tuning, LwF, EBLL, IMM, EWC, SI.
- on_whom: ImageNet-pretrained AlexNet on 2-task sequences (MIT Scenes, CUB Birds, Oxford Flowers) and an 8-task sequence (Flowers, Scenes, Birds, Cars, Aircraft, VOC Actions, Letters, SVHN); 5 permuted-MNIST tasks on a 512-unit 2-layer MLP; a "facts" (subject-predicate-object) image-embedding model on 6DS split into 4 tasks. 3 random trials in the vector-vs-L2 check. No language models.
- how_scored: Classification accuracy and drop on the first task (%); average forgetting (%) over a sequence; mean average precision for facts.
- result: Two tasks: fine-tuning drops the first task by 8% to 13%; MAS forgetting around 1% with new-task accuracy 0-3% lower than fine-tuning. l-MAS (Hebbian) averages 3% forgetting vs 1% for MAS. 8-task sequence: MAS average forgetting 0.49%, and average accuracy 2% above SI; SI then EWC are the next-best. Using the vector output instead of the squared-norm gave the same first-task drop (0.51% ± 0.18 vs 0.50% ± 0.19). Adaptation: computing importance only on one flower class gave 2% forgetting on that class vs 8% on Flowers overall, and 84% vs 69% on the last task (freed capacity). Facts: about 6% better MAP on the first two tasks. Quote: "agents should learn what (not) to forget."
- limits: Task boundaries needed; pretrained AlexNet only fine-tuned (mostly last layers in the classic setup); no replay; no language. Not applied to LLM fine-tuning in this paper.
- borrow: Output-sensitivity importance needs NO labels, so on our LLM it can be computed on the very prompts we care about (e.g. the order-sensitivity battery or the truth-probe statements) and used to protect exactly those behaviours during a LoRA fine-tune; the "importance computed on a subset only" adaptation test is a natural T7 (triage) arm: protect the tagged subset and measure whether it is spared more than untagged items.
- next_steps_it_suggests: Move toward systems that learn what to forget from their own usage frequency, online and unsupervised.
- already_run_check: T7 nearly (importance restricted to a chosen subset, which is then spared more: 2% vs 8% forgetting; but via a regulariser on a vision model, not replay, not LLM). T4 nearly (importance-weighted pull to old weights). Others: none.
- transfers: partly — label-free importance is directly usable on LoRA weights with our prompts, but the evidence is vision-only.
