# Language Models Need Sleep: learning to self-modify and consolidate memories — Behrouz, Hashemi, Javanmard & Mirrokni, 2026, arXiv preprint 2606.03979v2 (OpenReview version since Sept 2025, per the paper)
- url: https://arxiv.org/html/2606.03979
- field: machine learning
- read_depth: partial (first ~100k of 170k characters of the arXiv HTML: method, main results tables, ablations; efficiency appendix and later appendices not read)
- read_by: scout-bmq reader C, 2026-11-04
- what_tested: An offline "sleep" phase for LLM continual learning with two stages. (1) Memory consolidation: periodically add a new low-rank expert to a slower memory block and distil ("Knowledge Seeding": on-policy distillation plus an imitation reward mixing a semantic term and a Levenshtein token term) from a faster block into it, then reset earlier experts ("synaptic pruning"). (2) Dreaming: the model samples synthetic "dreams" conditioned on the task context, keeps the top-k by gradient-based importance plus b random ones, and LoRA-fine-tunes on them (SEAL / ReST-EM style, reward 1 if task performance improves). Compared with SFT, GRPO, OPSD, in-context learning, test-time training, SEAL, Cartridges.
- on_whom: Llama-3B, Llama3-8B (class-incremental CLINC/Banking/DBpedia, long-context tasks), Qwen3-1.7B and Qwen3-8B (AIME-24/25, HMMT-25), Llama-3.2-1B (few-shot ARC: 11 train, 8 held-out tasks); SQuAD knowledge incorporation (single passage; continued pretraining on n = 200 passages, 974 questions); MTOB/Manchu/Kalamang language learning; RULER MK-NIAH, LongHealth, QASPER, BABILong. Number of runs not reported in text read.
- how_scored: average@16 (math); no-context SQuAD accuracy; ARC success rate; ChRF (translation); class-incremental accuracy (figures).
- result: Qwen3-8B AIME-24 / AIME-25 / HMMT-25: base 73.8 / 68.1 / 42.4, SFT 75.5 / 66.4 / 43.7, GRPO 76.4 / 68.1 / 44.9, OPSD 76.6 / 67.4 / 45.1, Sleep 79.2 / 69.0 / 46.1. Qwen3-1.7B: SFT 47.3 / 36.1 / 22.9 (below base 49.8 on AIME-24), Sleep 53.2 / 40.2 / 29.3. SQuAD no-context (single / CPT n=200): base 31.9 / 31.9, fine-tune without dreaming 33.4 / 32.0, SEAL 46.7 / 43.2, Sleep 48.1 / 44.3. ARC: ICL 0%, TTT 10%, SEAL 72.5%, Sleep 80%. Ablations: removing dreaming drops SQuAD single-passage 48.1 to 35.7; removing gradient-based dream selection gives 47.1; removing imitation learning drops AIME-24 79.2 to 76.8. Forgetting under sequential language learning: SFT and Cartridges forget, ICL drops sharply, their model nearly recovers single-language performance (figure only). Quote: "Sleep is not a passive state but a dynamic and highly structured period".
- limits: In the text read: no raw-replay baseline (authors argue against raw replay but do not compare); no seeds/run counts; no test of order or context sensitivity after consolidation; no test of whether source information survives; dreaming draws only on existing model knowledge; SFT cost inside the SEAL loop limits dream count. Compute not reported in the text read; the method uses multi-block architectures (their "Hope"/multi-level variants) beyond plain fine-tuning.
- borrow: (a) Closest existing run of T2 on open-weight LLMs: context (short-term memory) is distilled into weights offline and then evaluated WITHOUT the context (no-context SQuAD), so "consolidation of in-context content into weights" is done. What is missing is exactly our measurement: after consolidation, is the judgement still order-sensitive, and does "my answer" vs "someone else's answer" survive. (b) The no-dreaming ablation (48.1 to 35.7) is a ready-made T3 effect size: self-generated rehearsal beats plain fine-tuning on the passage. (c) Gradient-importance dream selection (top-k plus random) is a T7 triage arm, with a small measured gain (47.1 vs 48.1).
- next_steps_it_suggests: Not stated explicitly in the text read; it flags iterative self-improvement as a forgetting risk.
- already_run_check: T2 nearly run (in-context content consolidated into weights on Llama/Qwen, scored by no-context recall; order sensitivity and source attribution NOT measured). T3 nearly run (dreaming vs no dreaming; no real-replay arm). T7 nearly run (importance-selected vs random dreams, small effect). Others: none.
- transfers: partly — the T2 idea is validated on open 1-8B models, but the full pipeline (SEAL-style outer loop, multi-block experts) is not a laptop job; a stripped-down version (self-generated QA on a passage, LoRA on Qwen2.5-1.5B/0.5B, then no-context test plus our order and source batteries) is.
