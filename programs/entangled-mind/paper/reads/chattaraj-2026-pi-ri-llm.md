# LLMs remember first, forget last: dual-process interference — Sourav Chattaraj & Kanak Raj, 2026, arXiv 2603.00270 (v3; comments say it appears in Springer LNNS, NPIR volume)
- url: https://arxiv.org/html/2603.00270v3
- field: cognitive psychology
- read_depth: full (via fetch summary of the HTML; appendix model table not seen)
- read_by: scout-bmq reader B, 2026-11-04
- what_tested: in-context AB-AC interference. 46 semantic categories, each assigned a first value and then updated N-1 times, interleaved, N in {3, 10, 50, 100, 200, 300}. Retroactive interference (RI) query = the FIRST value; proactive interference (PI) query = the MOST RECENT value; the input sequences are identical, only the query differs.
- on_whom: 54 LLMs tested, 39 with complete data (1B to an estimated 2.5T parameters; open families Llama, Qwen, DeepSeek; closed GPT-5, Claude-4.5, Gemini, o1, o3). Llama-3.1-8b is listed; Qwen2.5-7B and Llama-3-8B were not confirmed in the text read.
- how_scored: accuracy; endurance scores RIES / PIES = area under the accuracy curve over log N; bootstrap stopping rule (CI < 0.10, at least 5 sessions); error typology; temperature 0.
- result: PIES < RIES in all 39 models; mean gap 69.5 points (t(38) = 10.71, d = 1.73). RI accuracy 93.9% at N = 3, 72.9% at 100, 24.6% at 300; PI accuracy falls from about 94% to about 3%. Size explains RI (R^2 = 0.49) but not PI (R^2 = 0.06, n.s.); context window explains nothing (R^2 = 0.003). RIES-PIES r = 0.21 (n.s.). PI errors are mostly same-key intrusions (56.1%); over 97% of wrong answers carry no uncertainty signal. Hallucination under 1%. "Every model exhibits the same pattern: PI causes substantially greater degradation than RI."
- limits: (authors') one paradigm; mechanism (primacy bias, attention sinks) is post-hoc with no attention probing; parameter counts of closed models estimated; English only, temperature 0; bimodal PI sessions give wide CIs.
- borrow: in context, the FIRST binding wins (the reverse of humans in Bjork & Bjork's account, where PI grows only with delay). This is a candidate mechanism for our question-order effect (median ~25-point swing): if early context dominates, the first-asked framing should pull the rating more than the last. A $0 diagnostic on Llama-3-8B: vary the position of the biasing item (first vs last) holding content fixed. Their "no uncertainty signal on 97% of errors" also warns that confidence will not flag interference errors.
- next_steps_it_suggests: ecologically grounded update tasks; attention-head ablation and checkpoint comparisons on open-weight models to see whether the asymmetry is architectural or learned; positional debiasing.
- already_run_check: none of T1-T8 (in-context interference only; no weights changed). Relevant background for T2 and for the order-effect results.
- transfers: yes — the task is public-domain-simple and runs in context on both local models at $0; the mechanistic follow-up they ask for (head ablation on open weights) is feasible on Llama-3-8B.
