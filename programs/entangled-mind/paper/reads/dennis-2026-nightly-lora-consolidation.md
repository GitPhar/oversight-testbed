# Weight-based consolidation vs cascading compaction — Dennis, Shabahang, Guo & Patil, 2026, arXiv preprint
- url: https://arxiv.org/pdf/2605.24657
- field: machine learning
- read_depth: full (main text; Appendix A table header only, per-conversation tables not read)
- read_by: scout-bmq reader E, 2026-11-04
- what_tested: a nightly "sleep" pipeline modelled on complementary learning systems. (1) Reflection: Claude Sonnet 4 extracts procedural, semantic and episodic facts from long coding conversations (3 passes, union). (2) Synthesis: 20 paraphrased two-turn user-assistant conversations per fact, about 18,000 per source conversation. (3) Training: a LoRA on Qwen2.5-7B-Instruct, 8 epochs, tested with NO context. Compared against cascading context compaction (6:1 summary plus a new ~60k-token continuation, three cycles), a no-context floor and a full-context ceiling.
- on_whom: Qwen2.5-7B-Instruct, LoRA r=16, alpha=32, attention projections. 10 synthetic software-development conversations (50-65k tokens each, written by Claude Sonnet 4); 1,146 test questions (184 semantic, 154 procedural, 808 episodic). Answers judged by Claude Sonnet 4.
- how_scored: LLM-judged % of facts recalled (mean ± SE over n=10 conversations); paired t-test against compaction.
- result: overall, no context 11.8 ± 1.0; compaction after cycle 3 36.8 ± 3.0; consolidated 80.4 ± 1.3; full context 90.1 ± 0.9 (t(9)=14.78, p<0.001). By type, consolidated vs compaction: semantic 94.3 vs 62.0 (consolidation beats full context, 91.1); procedural 74.6 vs 36.3; episodic 78.2 vs 31.5. Consolidated retention stays flat at 80-82% across cycles. Dropping the in-context view costs about 10 pp. Across epochs, median token CE tracks fail rate (r=+0.994) while mean CE does not (r=-0.506).
- limits: one domain (coding). Facts are extracted and paraphrased by an external API model, so the "dream" content is not self-generated. Base-model forgetting is not measured (the authors chose not to run MMLU or HumanEval) and safety is not measured. Nothing on source (whose correction or preference it was), order effects, calibration, or confabulation of facts never stated. The conversations are synthetic.
- borrow: (1) the floor / compaction / consolidation / full-context ladder is the right frame for T2; (2) using the median rather than the mean token CE as the training signal; (3) the result that paraphrase diversity drives in-weight recall (citing Allen-Zhu & Li) is a design rule for any consolidation arm; (4) LoRA r16 on a 7B model fits mlx-lm on 16 GB with smaller synthesis sets. A $0 local version needs self-generated paraphrases (Qwen writing its own rehearsal set) in place of Claude.
- next_steps_it_suggests: other domains; extraction and synthesis on-device; standard benchmark and safety audits of each consolidated adapter.
- already_run_check: T2 nearly run on the retention side only. In-context conversation content was consolidated into 7B LoRA weights and recall measured. Not measured: order or context sensitivity of later judgments, own-vs-other source attribution, base-model forgetting. T3: no self-generated arm (an external model generates). T7: no prioritisation (all extracted facts treated equally).
- transfers: yes — the same model family (Qwen2.5-7B), LoRA, overnight consumer-hardware budget; the source and order measurements are the open slot.
