# Canonical-Context On-Policy Distillation (CCOPD) — Z. Lin, Liu, Quan, Zhang, Shi, Xu, Li, Luo & Zhu, 2026, arXiv preprint (v2, Oct 2026)
- url: https://arxiv.org/pdf/2605.30251
- field: machine learning
- read_depth: partial (abstract, sections 1-5.3, Tables 1-2, limitations, appendix D.6 checkpoint test; other appendices not read)
- read_by: scout-bmq reader E, 2026-11-04
- what_tested: "self-anchored drift". When a task's evidence arrives in pieces over several turns (RAW-SHARDED), the model's own earlier partial-information replies pull its final answer away from what it would say given the same evidence in one prompt (FULL). Diagnostics on the untrained model: masking the model's own commitment spans, replacing its earlier replies with neutral placeholders, and attention ratios. The fix is a context distillation into weights. A frozen copy reads FULL; a LoRA student reads its own RAW-SHARDED history; reverse KL is applied on the student's own final-answer prefixes. Pollution stress test: a wrong number planted as an earlier assistant solution vs as a user hint. A "required assistant checkpoint" test checks that the model still uses its own earlier output when it is needed.
- on_whom: Qwen3-8B-Instruct (main; LoRA, 6k math pairs from GSM8K/GSM8K-Aug), Qwen3-4B, Llama-3.1-8B-Instruct. Tested on 6 task families (math; code, function calling, text-to-SQL; table-to-text, summarisation) with 10 sampled rollouts per instance, plus AIME 2025.
- how_scored: accuracy / task score under FULL, CONCAT (all shards in one message, same order, no assistant replies) and RAW-SHARDED. KL deviation from FULL at matched prefixes. Neutral-replacement slope.
- result: Qwen3-8B math RAW-SHARDED 65.9 → 82.5 with FULL unchanged at 90.2. SFT on the same data 65.9 (+0.0); GRPO 74.8. All-domain RAW 41.7 → 55.1; FULL/CONCAT average 64.4 → 64.2. Pollution (math): baseline 90.2 drops to 33.0 with a wrong assistant-side solution and 63.1 with a wrong user-side hint; CCOPD holds 89.3 / 88.3. Neutral-replacement slope 0.537 → -0.087. Llama-3.1-8B: All-R 30.7 → 39.6 (+8.9). The checkpoint test is 82.5% on both the original and augmented tasks, so the model still uses its own earlier output when it is required.
- limits: shard order is fixed (the authors note that "user shards and their order remain fixed"), so this is presentation and history sensitivity, not question-order permutation. The authors say the pollution comparison "is not a role-matched trust test", i.e. own-vs-other source was not cleanly tested. Training is on deterministic synthetic shards. No measure of forgetting of base skills beyond FULL scores, and no graded or credence judgments.
- borrow: (1) the strongest existing evidence for half of T2: distilling a model's clean-context behaviour into weights cuts the pull of its OWN earlier turns (33.0 → 89.3 under assistant-side pollution); (2) the neutral-placeholder replacement and the 'required own checkpoint' control are exactly what an own-vs-other planted-answer test needs; (3) SFT on the same data did nothing (+0.0), so the distillation objective matters, and our T2 needs an SFT arm and a KL arm.
- next_steps_it_suggests: organic multi-turn failures with human-verified canonical contexts; training earlier-turn behaviour (clarification, abstention); calibrated use of helpful vs misleading assistant content.
- already_run_check: T2 nearly run. A distillation-into-weights step reduced sensitivity to the model's own earlier answers in context on 8B open models with LoRA. What differs: (a) no role-matched own-vs-other comparison (the paper says so); (b) no question-order permutation; (c) the content distilled is clean-context behaviour, not the model's own transcript answers; (d) binary task accuracy, not 0-100 credences. Others: none.
- transfers: yes — Llama-3.1-8B and Qwen 8B with LoRA, the same regime as ours; the role-matched own-vs-other version on our 0-100 rating task is the unrun piece.
