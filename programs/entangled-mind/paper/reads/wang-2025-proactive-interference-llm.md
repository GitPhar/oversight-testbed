# Unable to forget: proactive interference reveals working-memory limits in LLMs beyond context length — Chupei Wang & Jiaqiu Vince Sun, 2025, arXiv 2506.08184 (v3; ICML 2025 Long-Context Foundation Models workshop)
- url: https://arxiv.org/html/2506.08184v3
- field: cognitive psychology
- read_depth: partial (first 100k of about 106k characters of the HTML via fetch summary, i.e. everything except the tail of the appendix; the appendix model list was truncated)
- read_by: scout-bmq reader B, 2026-11-04
- what_tested: PI-LLM: a stream of key-value updates (up to 46 keys, values from 46 categories of 400 words, randomly interleaved), then a query for the LAST value of each key. Experiments vary updates per key (3-400), number of updated or tracked keys at fixed length, and value length (1-40 words); there is also a strictly sequential mode and prompt-based mitigations.
- on_whom: models from Qwen3-0.6B to DeepSeek-V3, about 637B (total count not confirmed in the text read; 30 open models enter the regression) (open: Qwen3 family, Qwen2.5-72B, Llama-4, DeepSeek V3/R1, Nemotron Llama-3.x variants; closed: GPT-4.1/4o, Gemini, Grok-3). Llama-3-8B and Qwen2.5-7B not confirmed in the text read.
- how_scored: retrieval accuracy; Interference Endurance Score (area under the curve over log updates); regression of IES on parameter class and context length (N = 30 open models).
- result: accuracy declines roughly log-linearly toward 0 as updates per key grow; mid-size models mostly reach 0% by 400 updates. Parameter class predicts IES (t = 3.03, p = 0.005); context length does not (t = -0.144, p = 0.886). Tracking 46 keys vs 2 at fixed length takes Llama-4 Maverick from about 100% to under 5%. A per-key "forget" instruction gives under 10 pp gain; "forward focus" prompts and a soft reset are largely ineffective; a mock QA turn that "closes" the earlier batch helps substantially. CoT does not help. "LLMs are unable to “forget” or “ignore” irrelevant prior updates."
- limits: synthetic key-value format only; prompt-wording dependent; regression excludes reasoning and closed models; the working-memory framing is an analogy, untested mechanistically; the mock-reset gain depends on discarding context.
- borrow: (1) the mock QA reset is a $0 intervention for our order effect: insert a closed fake user-assistant exchange between the earlier questions and the rated claim; if the ~25-point swing shrinks, the swing is PI-like. (2) The instruction-to-forget null fits our "consistency is memory" result: content in the transcript cannot be switched off by telling the model to ignore it.
- next_steps_it_suggests: mechanisms for instruction-driven suppression or unbinding of outdated content; benchmark interference resistance next to context length; mechanistic study of induction-like circuits.
- already_run_check: none of T1-T8 (in-context only). Code and data public (github.com/zhuangziGiantfish/Unable-to-Forget).
- transfers: yes — public code, in-context, runs on Llama-3-8B/Qwen2.5-7B at $0; it also gives an in-context interference challenge for the Ellenbogen-style T2 test (consolidated vs in-context facts under PI load).
