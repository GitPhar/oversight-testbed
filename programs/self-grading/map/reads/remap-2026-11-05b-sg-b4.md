## Reads

### User-assistant bias — Pan, Fan, Xiong, Hahami, Overwiening & Xie, 2026, ACL 2026 Findings (pp. 9220–9226), https://aclanthology.org/2026.findings-acl.449.pdf
- read_depth: full (main text and limitations; appendix tables not read)
- what_tested: whether a model relies on information under the user tag or the assistant tag when the two give conflicting values for the same entity, all else fixed. Synthetic multi-turn conversations (symbol = value; object colour), balanced on which role spoke last to remove position effects; a realistic rewrite; two debate sets.
- on_whom: 26 commercial models by API (Claude 3 Haiku, 3 Sonnet, 3.5 Sonnet, 3.7 Sonnet, 3 Opus, Sonnet 4, Opus 4; GPT-4, 4o, 4.1, 5, o1; DeepSeek; Gemini 2.0 and 2.5; Grok 3) and 26 open-weight base, instruct and reasoning models; 1,946 + 1,042 test conversations.
- how_scored: bias = (N_user − N_assistant) / (N_user + N_assistant), −1 (assistant-biased) to +1 (user-biased); log-probability ratio on open models.
- result: most instruction-tuned models are user-biased, up to about +0.8 (GPT-4o, 4.1); most Claude 3 models are significantly user-biased, Claude 4 and GPT-5 show "no obvious bias or low user bias", and reasoning models (Claude 3.7 Sonnet, Claude 4 Sonnet among them) are near neutral. Preference DPO raises user bias, reasoning SFT lowers it, and a few hundred DPO steps move it either way.
- limits: synthetic set-up, a narrow realistic check, an LLM judge on one debate set; no Claude 5.5 model.
- borrow: the balance on which role speaks last; the reasoning-trace finding (reasoning models track the latest value, not the speaker).
- next_steps_it_suggests: measure the bias in broader conversational settings; use the benchmark to audit role-tag effects.
- **Head: changes nothing.** It measures which role's *facts* a model relies on, not how harshly it grades text in its own turn, and its recent Claude models sit near neutral. So it gives no general tag bias that would predict sg-b4's direction or size, and no rival the follow-ups must exclude. A side note: reasoning models are near neutral, and Opus 5.5 always thinks. That is consistent with Opus's smaller own-turn gap, but it is not a test of it.

### JudgeSense — Bellibatlu, Raff & Zhang, 2026, arXiv 2604.23478 v3 (18 Sep 2026), https://arxiv.org/abs/2604.23478
- read_depth: full (main text §1–6 and the limitations; appendix tables partial)
- what_tested: whether a judge returns the same verdict when the instruction is reworded without changing what it asks; every item is judged four times (template A, A again, reworded B, B again), so wording sensitivity is scored against the judge's own same-prompt repeat agreement.
- on_whom: 25 judges from six providers (claude-haiku-4-5, claude-sonnet-4-5, claude-opus-4-7 among them); 880 items on four tasks (TruthfulQA factuality yes/no; SummEval coherence 1–5; TREC-COVID relevance A/B; MT-Bench preference A/B).
- how_scored: ΔJSS = JSS_paraphrase − JSS_repeat, with a declared threshold of 0.02; item-clustered bootstrap, and judges clustered by vendor for the pooled claims.
- result: rewording costs agreement on all four tasks. Coherence, the one graded task, loses the most (pooled −0.181; next factuality −0.057), and it is the largest loss for 14 of the 16 fully readable judges. Claude Haiku 4.5 on coherence: −0.206 [−0.258, −0.154]. Only coherence and factuality clear the threshold once judges are clustered by vendor.
- limits: one fixed set of five templates per task; English; flagship models under-represented; Sonnet and Opus preference cells cut short by budget; Opus 4.7 ran at the provider's default temperature.
- borrow: **a same-run, same-prompt repeat as the reference for every wording comparison**, and no reading of any cell whose repeat agreement is low.
- next_steps_it_suggests: report judge stability against a repeat baseline measured in the transport the judge will run in.
- **Head: design to borrow** (for both follow-ups). For the same-run re-grade: grade every cell twice in one run and read T against the same-run own-turn cells, which is what the audit asked for. For the lead-in swap: rewording an instruction that asks the same thing moves *graded* judgments well beyond repeat noise. So a one-line lead-in change on a 0–100 scale is a live carrier of L, not a long shot. It measures instability, though, not a directed shift.

### Bias in the Loop — Zhao, Esmaeili & Fard, 2026, arXiv 2604.16790 v1 (18 Apr 2026), https://arxiv.org/abs/2604.16790
- read_depth: partial (abstract, §3 research questions and design, §4.3 RQ2 results for Qwen3-4B, §5.4 implications, §6 threats, §7 conclusion; the RQ1 bias tables skimmed)
- what_tested: twelve prompt-injected cues (position, verbosity, authority, self-enhancement and others) in pairwise code judging, and test–retest reliability: the same case twice, same rubric and prompt, fresh sessions.
- on_whom: Qwen3-4B, Qwen2.5-Coder-3B and a GPT API model; code generation, code repair and test generation, by difficulty stratum.
- how_scored: micro accuracy against the gold candidate; Consistency Rate = share of items with the same decision on two runs.
- result: Qwen3-4B's consistency is in the low-to-mid 80s on code generation, the low 90s on repair and the 70s on test generation, lower on hard strata. Single cues swing decisions toward the option they favour.
- limits: two repeats per item, which the authors call a conservative estimate of instability; three judges, none of them Claude; pairwise only.
- borrow: fresh sessions per repeat; harder (more ambiguous) items carry more run-to-run noise. Haiku's per-study drift (−20 to +8 points on 10 studies, audit) is the kind of noise this predicts on items near a decision boundary.
- next_steps_it_suggests: more repeats under fixed settings; report repeat agreement beside accuracy.
- **Head: design to borrow** (for the same-run re-grade): two repeats per cell in one run, reported with their agreement, with the comparison drawn only within the run.

### Exploring Solomon's paradox — Grossmann & Kross, 2014, Psychological Science 25(8):1571–1580, DOI 10.1177/0956797614535400 (author proof, https://uwaterloo.ca/wisdom-and-culture-lab/sites/default/files/uploads/files/grossmann_kross_-_exploring_solomons_paradox_-_article_proof.pdf)
- read_depth: full (proof copy; supplement not read)
- what_tested: whether people reason more wisely about a friend's relationship conflict than their own, and whether a self-distancing instruction (own name and third-person pronouns instead of first-person) removes the gap.
- on_whom: three experiments, N = 693 (University of Michigan students; Study 3 younger 20–40 and older 60–80 adults).
- how_scored: a wise-reasoning composite (limits of knowledge, compromise, others' perspectives, change), first principal component.
- result: Study 1, other > self, F(1, 102) = 33.87, ηp² = .25. Study 3: self-distanced > self-immersed, t(442) = 2.61, p = .009. The self-distanced condition differed from the other conditions only marginally (p = .071), and a meta-analysis of that contrast over three samples was non-significant (d = 0.15). The gap is reduced to near zero, not shown to be zero.
- limits: hypothetical betrayal scenarios; self-report scales.
- borrow: nothing for a model test directly. The manipulation is a wording-only change in how the self is addressed.
- next_steps_it_suggests: other interpersonal situations; separate distancing from the self from distancing from any target.
- **Head: changes nothing** for the follow-ups' design, and it does not make sg-b4 known (a human analogue is not the same result). It does make a pure wording frame a plausible carrier of a self-other gap, which is the lead-in arm's question.

### LLMs get lost in multi-turn conversation — Laban, Hayashi, Zhou & Neville, 2025, arXiv 2505.06120, https://arxiv.org/abs/2505.06120
- read_depth: partial (fetch summary): the abstract, then the HTML's first 100,000 characters through the fetch tool's summary. The numbers below are the summary's, apart from the abstract's 39%.
- what_tested: the same task given fully specified in one turn (Full), as all its pieces in one message (Concat), or revealed one piece per turn with the model replying in between (Sharded).
- on_whom: 15 models, Claude 3 Haiku and Claude 3.7 Sonnet among them; six generation tasks; over 200,000 simulated conversations.
- how_scored: task performance and its spread over repeats (aptitude, unreliability).
- result: multi-turn performance is 39% below single-turn on average (abstract). Per the summary: Full about 90%, Sharded about 65%, Concat about 95% of Full. Information lost in rephrasing does not explain the drop; the multi-turn structure does.
- limits: simulated users; analytical tasks only; English.
- borrow: the Concat control, the same content collapsed into one message.
- **Head: rival named.** Message count and turn structure, apart from role, change model behaviour. sg-b4's quoted copy changes both role and message count (three messages to one), and its own §6 says it cannot separate them. The cheapest test that would is a quoted copy split back into three user messages. It is a candidate, about the price of the lead-in swap, and is **noted, not mapped**: it is not among the two cheapest, and the audit did not name it.

### Do LLMs benefit from their own words? — Huang, Choshen, Astudillo, Broderick & Andreas, 2026, arXiv 2602.24287 v1, https://arxiv.org/html/2602.24287v1
- read_depth: partial (fetch summary of the first 100,000 characters)
- what_tested: multi-turn conversations with the assistant's earlier replies kept (Full Context) or replaced by a placeholder (Assistant-Omitted).
- on_whom: Qwen3-4B, DeepSeek-R1-Distill-Llama-8B, GPT-OSS-20B, GPT-5.2; 300 technical conversations from WildChat and ShareLM; GPT-5 as the pairwise judge.
- result (per the summary): omitting the assistant's own earlier replies often does not hurt and sometimes helps; models carry their own earlier errors forward ("context pollution").
- **Head: changes nothing.** It is about whether a model's own earlier text helps it answer, not about how it grades that text, so it bears on neither follow-up's pass rule.
